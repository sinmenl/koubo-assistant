# 口播助手行为验收案例

这些案例供人工或另一次模型会话逐项验收。本轮已按下列状态执行有限烟测，实际输出与首轮失败记录见 [烟测记录](../docs/SMOKE-20261022.md)。结构检查器和单元测试不会执行模型，也不证明下列行为已经通过。材料均为虚构测试输入，不可当作用户经历或写入个人记录。

每次记录：项目版本、模型与日期、输入、实际输出、通过／未通过、证据位置。没有执行的案例写“未执行”。
