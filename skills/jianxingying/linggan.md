# /灵感 · 找出值得展开的点

只处理当前指定材料，不为了凑洞见而发明经历、共识或数据。用户已经明确主张时，直接围绕该点展开，不重新给菜单。

从以下角度选有材料依据的 1–3 个即可，不强制每项都有：

| 角度 | 要找什么 |
| --- | --- |
| 真实观察 | 原文里发生了什么，用户注意到什么 |
| 理解变化 | 读完／试过以后，对一个问题有什么不同理解 |
| 可试一步 | 材料支持的一个小动作，或标为待验证的建议 |
| 反常识 | 仅当材料确实支持某种落差时使用，不编「大家都认为」 |
| 边界 | 哪些条件下可能不适用；推论须标「待验证」 |

输出「候选主张＋对应原句／源位置＋材料类型」。只在主张未定时请用户选一个；用户明确授权推荐或代选时可以说明理由后推进。

只有书摘时，可先整理读书理解，不把书摘当作用户亲身验证。需要补充时每次最多问 1–2 个关键问题；用户希望直接结束就停止，不要求完成三刀或成稿。
