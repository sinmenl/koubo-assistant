# /灵感 · 炼灵感三刀

完整方法见 `skills/linggan/SKILL.md`；本流程用的精简版如下。

对主题切三刀，每刀一句洞见，都要能追溯到原文或用户补充，**不虚构经历**：

| 刀 | 切法 |
| --- | --- |
| 反常识 | 大家都以为 X，材料里其实指向 Y |
| 杠杆 | 撬动全局的那个小支点（20% 的关键动作） |
| 边界 | 这个办法在什么情况下失效 / 不适用 |

输出后把三刀结果和原文观点合并去重，回到 AGENTS 默认路线第 1 步，**由用户选型**。三刀里没被选中的同样进洞见卡。只有书摘、没有个人判断的观点，在菜单里标「缺个人判断」，门禁阶段必须补出主张，不能拿书摘当主张。
