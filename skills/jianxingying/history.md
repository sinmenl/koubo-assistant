# /翻旧账 · 找回可核实材料

目标是找回与当前主张有关的来源，不把旧故事自动安到本期头上。

1. 先承接本轮已明确的主张；只在主张未定时列候选，不重复选题。
2. 检索范围限本对话和当前项目中用户指定或已授权的材料位置。先查明确来源，再查已启用的当前身份记录；不跨用户、跨项目或扫描私人目录。
3. 可列 1–3 条线索，每条给出短摘录、来源位置和归属。会话摘要、旧卡、AI 稿只作检索线索，须回到原文核实；没有找到就如实说「当前范围未找到」。
4. 只有要把历史经历并入本期第一人称时，才请用户确认使用哪条。确认前不写入定稿；他人的事始终保留他人归属。
5. 每次最多问 1–2 个必要问题。用户不补、都不用或明确结束时，直接承接其选择；可以保留为观察／读书理解／待验证想法，也可以不成稿。

旧 `memory/`、`style-profiles/` 下的个人文件只在用户明确指定迁移时读取；模板不是个人经历来源。找到一条材料不代表已获得上传或保存授权。
