# /翻旧账 · 钉回时刻 + 主动回顾历史（完整版）

二次分享常常只有判断、没有场景。目标是把本期主张或感受**钉回一个真实时刻**，并**主动摊开**相关历史分享让用户选。不是「想不起来才翻旧账」，也不是替用户默认用某一次。

## 判定需要补钉（满足任一）
- 用户说「还是上次那个点 / 迭代一下 / 上次讲过」
- 有主张或感受词，但几乎没有时间、场合、人物、数字
- 门禁「细节」关过不去
- 本对话 / 已存洞见卡 / `inbox/` 里能搜到同题旧材料（即使本轮已有一点场景，也可以拿来对照）

## 怎么补（一般一轮输出）
1. **问时刻：**
   > 你是在什么时候遇到这种感受的？当时在做什么、跟谁、发生了什么？（一个具体瞬间就够）
2. **主动回顾（有就必须列，没有就写「库存暂无同题」）：** 按 本对话上文 → 已存洞见卡 → `inbox/` 的顺序，找 1–3 条同题线索，每条一行（半句场景 + 来源），然后固定问：
   > 下面这些以前的分享，要用哪一条补进本期？也可以都不用，你另说一个时刻。
3. 用户选定「某条历史 / 新说的时刻 / 都不用、另写」之后，才写进本期「证据」。口播只讲确认过的那一段；洞见卡的「待补」也可以据此补上。
4. 用户既不选也不补 → 停在补齐，不成稿，也不要当作分享已经结束。

## 禁止
- 没确认就把旧文写进定稿
- 替用户勾选「就用这条」
- 把旧文里的感受词自动安到本期头上
- 编造用户没说过的时刻
- 用书摘或别人的故事顶替

（用户以为「分享完就结束」时提醒：抽象的迭代要先钉回真实时刻，才能升级成洞见卡或口播。）
