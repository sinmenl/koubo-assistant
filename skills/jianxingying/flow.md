# /顺一下 · 检查和调整口播

先读 [dependencies.md](dependencies.md)，按其中顺序寻找 `dbs-script-flow`；依赖不可用时直接按下述标准处理。

- 只处理当前稿件的句子、顺序、衔接和信息密度，不重新选题、增加故事或扩大制作任务。
- 子模块是辅助工具；本次不承接其额外安装、上传、保存或其他可选流程。
- 检查指代是否清楚、前后是否接得上、一个句子是否塞太多意思、读出来是否需要长时间憋气。
- 不强制反常识、五段骨架、固定秒数钩子或问句收尾；按稿件用途保留自然节奏。

用户要检查：给 1–3 处「原句 → 问题 → 最小修法」。用户说「顺一下／帮我改」已包含改稿意图，直接给干净可念的修订稿，再简述主要改动，不另等一句「直接改」。

来源不清或逻辑缺项时标出来，每次最多问 1–2 个必要问题；不靠补造经历填空。没有计时录音时，只能估算时长。
