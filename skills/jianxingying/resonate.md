# /共鸣 · 共鸣诊断

先按 AGENTS Step 0 就绪 dbskill，然后**实际读取并执行** `skills/dbskill/dbs-resonate/SKILL.md`（不走 `/dbs` 调度台；若用本机已装包，读取该包对应的实际路径），对**用户选定的主张 + 证据 + 相关原文**做诊断。

自动检查时，以「本期串联」作为待检查半成品，不提前编写或交付完整口播。不更换已选主张、不新增经历或感受。该 Skill 的诊断完成后返回 AGENTS 第 3 步，原来的反常识、细节、避坑门禁照常执行；缺什么仍按原规则补齐。单独 `/共鸣` 请求则交付诊断即可。

输入整理：
```
目标受众：践行营同伴。不要代写感受。
【主张】…
【证据】…
【画面】…
【反常识落差】大家以为…其实…
【原始流水账中与该主张相关的段落】…
```

输出要短：
1. 核心主张一句话（来自用户选定的点，不新造经历）
2. 主张状态：清晰 / 被稀释 / 缺失
3. 断点：哪些原句该删、该压、该强化
4. 骨架预告：钩子 → 痛点/反常识 → 证据场景 → 可执行一步 → 收束提问
