# /共鸣 · 检查稿件与受众的连接

先读 [dependencies.md](dependencies.md)，按其中顺序寻找 `dbs-resonate`。无可用依赖时直接按本文件做。

## 任务边界
- 用户已确定的主张、素材与受众直接承接，不重新扩选题。
- 子模块只辅助诊断稿件；其可选扩展、安装、保存或上传流程不在本次任务内。
- 区分个人观察、读书理解、他人案例、待验证想法。共鸣不能靠增加没说过的感受、编经历或制造「大家都以为」。反常识是可选表达。

输入用当前稿全文、主张及来源；受众不明且影响判断时，最多问 1 个问题，否则说明按现有语境判断。

输出简短列出：
1. 主张是否清楚，哪一句承担核心意思。
2. 最可能让目标读者接不上的 1–3 处：原句、原因、最小改法。
3. 哪些地方有来源支撑，哪些是需要限定范围的推论。
4. 一个最值得先改的地方。

用户只要诊断就先报告；已明确要求改稿就直接给修订稿。保留主张与事实，不强套五段结构或问句结尾。结论是文本判断，不预测播放量。
