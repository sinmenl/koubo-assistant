# /共鸣 · 共鸣诊断

先按 AGENTS Step 0 就绪 dbskill，然后**直接读** `skills/dbskill/dbs-resonate/SKILL.md`（不走 `/dbs` 调度台），对**用户选定的主张 + 证据 + 相关原文**做诊断。

```
目标受众：践行营同伴。不要代写感受。

【证据】…
【画面】…
【反常识落差】大家以为…其实…
```

输出要短：
1. 核心主张一句话（来自用户选定的点，不新造经历）

3. 断点：哪些原句该删、该压、该强化
4. 骨架预告：钩子 → 痛点/反常识 → 证据场景 → 可执行一步 → 收束提问
