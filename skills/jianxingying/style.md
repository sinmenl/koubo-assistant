# 风格进化 · 风格档案写入细则

路径：`style-profiles/{用户标识}.md`（无标识用 `default.md`；目录不存在就创建）。**只记文风（怎么说）**；「这期做了什么」写进 `memory/`，不要混在一起。

## 读
写口播前，档案存在就先读全文，按里面的用词、句式、开头和结尾偏好、禁忌来写；档案没有的维度才用 AGENTS 默认骨架。

## 写（默认要做；用户说「这次别记风格」才跳过）
- 时机：用户收下稿、贴回修改稿，或说「按这个改 / 定稿」。
- 对比 **Agent 生成稿** 和 **用户改后稿**（用户只口头说改哪里，就按口述记）。看这些：改了哪些词、句子长短、口语还是书面、开头钩子、收尾问法、常删的套话、常加的口头禅或节奏。
- **累积更新**：有对应小节就改，没有就追加；不要整份推倒重写，抹掉以前的积累。结构参考 `style-profiles/_template.md`（更新日期 / 调性 / 用词偏好 / 句式节奏 / 开头 / 收束 / 本次学到的，带日期追加）。
- 用户这轮没改 → 可以记一条「本轮无改动」，也可以不写，但要说一句「本轮无风格更新」。
- 写完只说一句「已写入风格档案，下次会按这个写」，不念整份档案。
- 不记隐私八卦，不把用户没确认的经历写进档案。多用户分文件，不混写。
