# memory 写入细则

分工：`inbox/` 存原始流水账；`style-profiles/` 只记文风；`memory/` 记「这期做了什么」，供 7 天复盘时快速浏览，不替代 inbox。

## 时机
本期选型结束后都要记一条：成稿要记，明确停在补钉 / 选型 / 不成稿也要记（方便复盘时看出卡在哪）。用户说「这次别记 memory」才跳过，并说一句确认。

## 做法
1. `memory/` 不存在就创建；打开或创建 `memory/{用户标识}.md`（无标识用 `default.md`）。
2. 新文件先按 `memory/_template.md` 写文件头；已有文件只更新「最近写入」日期。
3. **只追加，不删旧条：**
```markdown
## YYYY-MM-DD · 本期主张一句话
- **钉回的时刻：** 用户确认的一句；没有就写「未钉」
- **成稿：** 是 / 停在选型或补钉
- **洞见卡：** 卡标题列表（本期未拍）
- **用户反馈：** 改稿要点一句；没有就写「—」
- **可复盘标签：** 主题词 2–4 个
```
4. 只说一句「已写入 memory，/复盘 可看近 7 天」，不念全文。

## 隐私
不记隐私八卦；时刻摘要只用用户确认过的措辞；不写没确认的经历。多用户分文件，不混写，也不写进 style-profiles。
