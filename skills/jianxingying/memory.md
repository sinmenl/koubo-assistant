> 什么时候读：用户明确保存本期，已启用会话记录且本期结束，或询问记录如何处理。

# 会话记录 · 默认关闭

配置模板为 `config.example.json`，个人配置放 `local/config.json`：
- `profile_id`：当前身份的安全标识；只用字母、数字、短横线或下划线，禁止路径、斜杠和 `..`。
- `record_sessions: false`：默认不记会话。
- `learn_style: false`：文风学习独立控制，见 [style.md](style.md)。
- `timezone: "Asia/Shanghai"`：日期按此时区，用户明确指定其他时区时从其设置。

用户明确要求「保存这期」是本期保存授权，不代表永久开启；只有用户明确启用后才改变配置。身份已确定就承接，不重复问。身份未定且需要写入时先确认，不能回退到 `default.md`。

## 保存方法
1. 未启用且无本期保存要求时不创建个人记录。启用后仅在用户明确收稿、定稿或结束本期时记录；等待补充不自动当作结束。
2. 一期一个 `session_id`，使用 `YYYYMMDD-HHMMSS-短后缀`，后缀只含字母数字。路径为 `local/sessions/{profile_id}/{session_id}.md`；同一期修稿沿用该 ID。
3. 使用 `memory/_template.md`。记当前主张、材料类型、源位置、结果和用户确认的反馈；不复制整篇私密原文，不写未确认经历。
4. 同一期只保留一份当前记录，迭代时更新状态并在「变化说明」追加日期与变化，不能把每次改稿算新一期，也不删掉关键变化。
5. **成稿状态**与**拍摄／发布状态**分别记。后者仅用「未知／未拍／已拍／已发布」，须有用户反馈或可核实证据，不根据生成稿推断已拍或未拍。
6. 写入后读回确认，再简述保存位置；没有落盘能力或写入失败时说明结果，不宣称已保存。

## 读取边界
只读当前已授权身份的记录和用户指定来源；历史摘要、卡片和 AI 稿只作线索，不能冒充原话。旧 `memory/`、`style-profiles/` 中的个人文件，须用户明确指定迁移后才读取。所有个人文件保留在被 Git 忽略的 `local/`，不会因保存记录而获得上传授权。
