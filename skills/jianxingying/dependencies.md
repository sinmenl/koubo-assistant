# 可选依赖：只读所需工具，不自动安装

`/共鸣`、`/顺一下`、`/标题`可以借用 dbskill；默认口播、卡片、灵感和复盘均不依赖它。

## 解析顺序

1. 检查项目内 `skills/dbskill/{目标名}/SKILL.md`，存在就读这一个。
2. 不存在时，只在宿主已列出的安装路径或用户提供的路径查找同名工具；例如宿主声明的 `~/.agents/skills/{目标名}/SKILL.md`。不要扫描整个磁盘或复制全套。
3. 都没有：用当前功能模块中的简版规则完成请求，简短说明“本次使用内置简版”；不假装运行过外部工具。

| 当前任务 | 目标工具 |
| --- | --- |
| 共鸣检查 | `dbs-resonate` |
| 口播流畅检查 | `dbs-script-flow` |
| 标题／封面文字／开头 | `dbs-title-cover-intro` |

## 调用范围

- 把当前主张、已确认素材、指定受众及本次请求一起交给目标工具；当前主流程决定范围。
- 已有定稿只要标题，就直接做标题；不因工具的通用流程再次扩选题。
- 不读取整个调度台，不执行上游更新提示、安装脚本、保存或外部发布步骤，除非用户另行明确要求。
- 读书理解不能被工具补成亲身经历；可选工具不能覆盖本项目的真实性和个人记录规则。

## 安装与更新

只有用户明确要求时才按 [dbskill 官方仓库](https://github.com/dontbesilent2025/dbskill) 的说明安装或更新。不要硬编码“缺依赖就全局安装”。这个项目的 Git 更新不同时更新第三方工具。

旧分发包内的 dbskill 可继续本地使用，本项目忽略该目录上传。它有自己的许可与版本，见 [来源说明](../../THIRD_PARTY.md)。
