> 什么时候读：用户说 `/复盘` 或 `/7天复盘`（可以后跟用户标识）。和口播主流程并列，不用重跑口播。

# /复盘 · 7 天复盘

1. 读 `memory/{用户标识}.md`（没有标识就读 `default.md`）。没有这个文件 → 说一句「还没有 memory，先跑几期 /口播」，结束。
2. 筛**最近 7 天**的条目：按条目标题 `## YYYY-MM-DD` 的日期，以用户本地日为准（Asia/Shanghai，或用户本机日期）。
3. 按固定结构输出（简体中文，简短）：

```markdown
## 近 7 天复盘（YYYY-MM-DD ~ YYYY-MM-DD）
### 做了几期
- 成稿 N / 停在补钉或选型 M
### 主张与主题
- （列表：日期 · 主张 · 标签）
### 还没拍的洞见卡
- （合并近 7 天的卡标题，去重）
### 卡住的地方
- （没钉回的时刻 / 没选型 / 用户说跳过 等）
### 下一周可拍候选
- （从洞见卡或未完成条目里列 1–3 个，请用户选；不替用户拍板）
```

## 硬边界
- 复盘只依据 memory 和用户当面补充的内容，不编新经历。
- 「下一周候选」要用户确认后才进入 `/口播`。
- 多用户时只读对应用户的文件，不混读。
