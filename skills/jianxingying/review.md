# /复盘 · 近七天回看

1. 承接已确定且授权的 `profile_id`，只读 `local/sessions/{profile_id}/`。若身份不明且目录有多人数据，先确认身份，不能混读或用 `default.md`。
2. 默认范围为配置时区下的今天及前六个自然日。按记录的会话日期筛选，同一期按 `session_id` 只计一次，修订日期不把旧期挪成新期。
3. 没有记录就如实说明，并允许用户提供本次想复盘的材料；不要求先跑几期或开启自动记录。旧个人文件只在用户明确指定迁移时读取。
4. 依据记录区分「成稿／未成稿／用户选择结束」，不要把主动不拍解释成卡住。拍摄／发布状态独立，未知不能计为未拍。

简短交付：
- **做了什么：** 会话数、成稿数，以及记录中可确认的拍摄／发布状态。
- **主张与来源：** 日期、主张、材料类型和记录位置。
- **可继续的点：** 未完成记录或卡片标题，缺少什么；不补造经历。
- **一个下一步：** 从实际记录提出小动作。只有用户想选下一期时才列 1–3 个候选，确定后直接承接主张。

结论只覆盖当前范围，不凭七天记录推断用户性格或长期规律。复盘默认仅在对话中输出；另行保存仍遵守 [memory.md](memory.md) 的授权。
