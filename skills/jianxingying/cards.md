# /存卡 · 洞见卡四件套（践行营补充规则）

基础铸卡方法见 `skills/dongjian-card/SKILL.md`；本流程额外要求如下。

## 规则
- **洞见卡不是读书笔记。** 每张都要有四件套，还要附上**本次流水账里与该点相关的全部原文**（可整段摘录或按顺序串联，标明出自本次流水账），不要只留半句碎片。
- 缺哪一件就空着，标「待补」，不用空壳金句凑数。
- 机理和方法只依据原文或用户补充，不编经历。有经用户确认的时刻，就尽量把「待补」补全。
- 卡片不能喧宾夺主：可以和口播同一轮交付，但放在口播后面。
- 成稿后拆出的旁支主张也按这个格式补卡，不要只写进改动说明。

## 模板
```markdown
## 洞见卡（本期未拍）

### 卡 1 · {短标题}
- **一句话要点：** 这张卡解决什么问题
- **机理：** 为什么成立；因果链；有原文依据
- **可执行方法：** 第 1 / 2 / 3 步，别人照着能做
- **边界条件：** 什么情况下不适用；常见坑
- **本次流水账相关原文：** 相关句段，可串联
- **可做下期角度：** …
```
