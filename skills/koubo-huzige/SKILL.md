# 内容炼金提示词 - 蒸馏版
## 核心目标
把原始素材快速转化为**可直接拍摄的口播逐字稿**。
质量标准：洞见优于鸡汤 | 可验证优于绝对论 | 可执行优于空泛励志
---
## 快速启动
**投喂素材时：**
```
选题/观点：[核心主张]
故事/案例：[具体事件或数据]
目标时长：[3min / 5min / 7min+]
```
**输出：**可直接念的逐字稿 + 洞见标注
---
## 8大叙事库（触发信号速查）
| 库名 | 触发信号 |
|-----|--------|
| 问题反转 | \"大家都这么做，但其实...\" |
| 单一解药 | \"有个方法改变了我...\" |
| 成本降维 | \"怎样快速/便宜/简单地...\" |
| 阶段跨越 | \"初级→中级→高级\" |
| 权力转移 | \"从被动到主动\" |
| 身份撬动 | \"当我意识到我是...\" |
| 因果颠倒 | \"你以为的原因其实是结果\" |
| 缝隙机会 | \"没人做，但可以...\" |
---
## 黄金骨架（7步）
1. **开场** → 一句话主张 / 问题 / 反常识（15-20秒）
2. **PROBLEM** → 现状困境 + 为什么 + 代价（30-45秒）
3. **故事/案例** → 发生了什么 → 转折点 → 结果（60-90秒）
4. **观点萃取** → 核心洞见一句话（20-30秒）
5. **对标迁移** → 2-3个不同场景的类比（30-45秒）
6. **落地行动** → 现在可以做什么 → 成功标志（15-20秒）
7. **结尾** → 回应开场 / 反问（10-15秒）
---
## 质量防线
✅ **必须有：**
- 具体的故事或数据（不是纯概念）
- 核心观点能一句话说清楚
- 至少一个可验证的逻辑链
- 用\"通常\"\"大多数\"代替\"永远\"\"所有人\"
❌ **禁用：**
- 没有来源的论断
- 鸡汤式励志空泛语
- 因果链跳跃（A→C，缺B）
- 无边界的绝对结论
- 编造案例/数据/数字
---
## 快捷指令
**\"诊断\"** → 找出逻辑缺失的具体位置，标注修复建议
**\"打磨\"** → 调整口吻，让逐字稿更可念
**\"对标\"** → 找3个不同领域的同类解法
**\"上强度\"** → 质疑论述，找缺口和反例
**\"最小化\"** → 压缩到1分钟版本
---
## 深度视频微调（5min+）
PROBLEM段超过45秒时，改成**「铺垫递进」：**
- 把大问题拆成两个小问题
- 先问第一个，停顿，再问第二个
- 让听众体验\"认知逐层打开\"的感受
