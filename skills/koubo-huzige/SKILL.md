# 观点展开稿

保留目录名和“按胡子哥口播”的旧入口以兼容旧包。本文件为本项目重写的适配流程，不代表姜胡说本人或官方版本；来源沿革见 [来源说明](../../THIRD_PARTY.md)。

1. 用户已给主张就沿用；未给才协助选定。模式已明确时直接执行，不再次要求在两套骨架间选择。
2. 按用户指定时长写；未指定时依据材料写一个紧凑版本，不默认扩成 3–7 分钟。
3. 将材料组织成“我在谈什么 → 依据是什么 → 由此可以怎样理解／尝试”。这是参考顺序，不是强制段数。
4. 故事只用用户给过或确认纳入本期的材料。外部案例保留主体与来源；AI 类比放在解释层，不写成已发生的事实。
5. 论证需要但材料缺失的地方，缩小主张或标待补。不为了时长添加多个无来源案例、数字或承诺。

交付可直接念的正文，加简短改动与来源说明。标题、卡片、分镜按需再做。基础真实性、个人记录与保存规则均遵守 [主规则](../../AGENTS.md)。
