【口播助手 0.2.0 · 怎么用】

把整个项目放在单独文件夹，让你的 AI Agent 先读 AGENTS.md。
直接贴材料，说 /口播；已选观点就一起告诉它，无需反复选题。
也可以只说 /标题、/顺一下、/存卡、/灵感、/翻旧账、/复盘 或 /诊断。

不编经历，不把别人的故事当成你的；反常识和固定骨架不是必选。
个人记录和风格学习默认关闭，需要时再按 README 配置，资料留在 local/。
更新项目规则不会更新个人资料；旧指令图不再作为新版指南。
可选 dbskill 不随 Git 分发，也不会自动安装，缺少时基础流程仍可用。

来源、更新与检查方法都在 README.md。当前 GitHub 仓库是私有项目；如需另行分享，先确认访问权限与来源范围。
