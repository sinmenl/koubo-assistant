# 0.2.0 迭代说明

目标是让已有口播流程少一些重复选择和硬性套路，同时把个人使用数据留在本机，使项目规则可以持续更新。

| 原行为 | 本轮调整 | 为什么 |
| --- | --- | --- |
| 有观点仍先列菜单；标题再次选题 | 识别已选观点、局部修改和单独标题请求 | 接住当前任务，减少往返 |
| 反常识、场景、避坑全部过关才能写 | 检查主张、来源和证据范围；结构按材料选 | 普通真实表达也应能成稿，不诱导补造经历 |
| 每稿五段并以问句结束 | 正文干净可念，结尾自然 | 减少模板腔 |
| 自动记 memory／风格，身份缺失回退 default | 默认关闭，明确身份，个人配置在 local | 避免串档和把 AI 文句学成用户风格 |
| 改一次记一期；成稿约等于未拍候选 | 稳定 session ID，分开记录成稿与拍摄发布 | 复盘只统计实际知道的状态 |
| 缺工具自动全局安装 | 项目内 → 已安装 → 内置简版 | 创作任务不触发机器级修改 |
| 高播放断言进场强，套固定完播率阈值 | 核对口径与窗口，事实／假设／验证分列 | 数据不足时保留不确定性 |
| 压缩包只有文件，没有更新路径 | 独立 Git 项目、版本日志、忽略个人资料、自动检查 | 后续可以小步更新和回看 |

## 本次范围

原始包已在仓库外完整备份。旧第三方副本与指令图只在本地保留，不进入 Git。没有改动父项目里的逐字稿、海报或名单，也没有把它们带入仓库。

八个虚构案例已做有限行为烟测，其中两处首轮问题修正规则后重测，见 [烟测记录](SMOKE-20261022.md)。结构检查与模型行为验收分开记录。工具能核对链接、版本和提交范围；模型测试用虚构材料，不能据此承诺真实创作效果。

## 后续从反馈继续改

优先观察：是否还反复问已经给过的信息、是否出现用户没有说过的情节、成稿读起来是否自然、可选记录是否好用。每次留一个具体失败例子，再改最相关的规则；暂不增加更多模式和评分体系。
