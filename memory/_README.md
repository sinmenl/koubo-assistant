# memory · 践行记忆（给人看）

与 `inbox/`、`style-profiles/` **同级**，互不混写。

## 三目录分工

| 目录 | 记什么 | 不记什么 |
| --- | --- | --- |
| `inbox/` | 原始流水账库存（用户贴的长文） | 不整理成结论 |
| `style-profiles/` | 只记文风（怎么说） | 不记本期做了什么 |
| `memory/` | 「这期做了什么」——主张、钉回的时刻摘要、洞见卡标题、是否成稿、用户反馈一句 | 不替代 inbox；不记隐私八卦；不把未确认经历写入 |

## 文件约定

```text
memory/
├── _README.md          # 本说明
├── _template.md        # 单条会话记忆模板
└── {用户标识}.md       # 一人一份累积日志（无标识用 default.md）
```

- **只追加，不删旧条。** 复盘时按条目标题日期筛最近 7 天。
- 时区按用户本地日（文档约定：Asia/Shanghai / 用户本机日即可）。

## 怎么复盘

对 Agent 说 **`/复盘`** 或 **`/7天复盘`**（可后跟用户标识）。Agent 会读 `memory/{用户标识}.md`，按近 7 天输出固定结构；「下一周可拍候选」须你确认后才进入 `/口播`。

## 口播结束会自动记一条

主流程结束固定步（AGENTS 默认路线第 6 步，细则见 `skills/jianxingying/memory.md`）：本期选型结束后（成稿或停在补钉/不成稿）追加一条；你说「这次别记 memory」才跳过。
